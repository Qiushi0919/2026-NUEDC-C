# 电机与PID控制模块优化规划

## 1. 电机限幅函数

- 当前电机输出 PWM 值未进行统一限幅处理。
- 建议：新增一个 `Motor_Limit_PWM()` 函数，对所有电机输出进行统一限制，防止过载或异常动作。

```c
int16_t Motor_Limit_PWM(int16_t pwm_input, int16_t pwm_max);
```

---

## 2. 巡线 / 角度 / PID 对应的 `setPWM` 函数整合

- 目前存在多个 `setPWM` 类型函数，功能重复且不利于维护。
- 建议：将以下三种模式统一封装进 PID 控制模块，并根据 PID 类型（如位置式、增量式）进行区分调用。

| 模式类型 | 原始函数名 | 封装建议 |
|----------|------------|----------|
| 巡线模式 | setPWM_LineFollower() | 统一归入 PID 模块 |
| 角度控制 | setPWM_AngleControl()   | 根据 PID 类型封装 |
| PID通用  | setPWM_PID()            | 提供统一接口 |

---

## 3. 多轮电机 PID 控制统一管理

- 当前四轮电机（FR, FL, RR, RL）各自使用独立的 PID 结构体，不易于扩展和维护。
- 建议：
  - 统一轮子的 PID 控制逻辑；
  - 使用结构体数组统一管理，例如：

```c
typedef struct {
    PID_Struct pid;
    uint8_t pid_mode;
} Motor_PID_Instance;

Motor_PID_Instance motor_pids[4]; // 支持四个轮子
```

---

## 4. PID 计算函数统一封装

- 当前速度、角度、阿克曼等不同模式下使用了不同的 PID 计算函数，导致代码冗余。
- 建议：统一封装成如下两个核心函数：

```c
void PID_Compute_All(Target_Info *target); // 统一计算所有PID
void Motor_Kinematic_Analysis(Target_Info *target); // 运动学分析
```

- 功能描述：
  - 输入目标速度与角度；
  - 输出各轮电机的目标 PWM 值；
  - 所有 PID 计算均基于此流程运行；
  - 仅在 speed 模式下调用该流程。

---

## 5. A-B行走路径优化：双环PID支持

- 当前 A-B 行走路径控制只使用了角度环 PID。
- 建议：一个月内实现双环 PID 控制（速度 + 角度），提高路径跟踪精度和响应稳定性。

### 实现计划：
- 增加外环（角度控制）和内环（速度控制）；
- 调整 PID 参数协调性；
- 验证闭环反馈系统的稳定性。

---

## 6. 电机PWM设置函数合并优化

- 当前存在四个类似函数（如 `Motor_PwmSet_FR`, `Motor_PwmSet_FL` 等），代码冗余严重。
- 建议：重新考虑是否可将其封装为统一接口函数，避免重复代码。

### 可能方案：
- 使用枚举或索引标识电机编号；
- 使用统一函数处理 PWM 设置；

```c
void Motor_PwmSet(Motor_Index_e index, int16_t pwm_value);
```
