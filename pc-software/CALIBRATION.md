# 定位校准说明

## 当前部署方案

当前使用现场测试确定的场地畸变校准 v3，旧的45点二维查表和三次角度回归不再参与最终结果。

处理顺序：

1. 按基站原始角度和原始中心距查找全局校准二维区间，并分别加上该格的距离、角度修正值；
2. 对全局校准后的结果执行可选的5点中值预滤波；
3. 距离直接采用中心距，角度执行场地分段映射；
4. 界面上的距离、角度人工微调；
5. 输出平滑（默认30点中值），界面按实时帧率显示估算总延时；
6. 身份验证、距离分区、声光控制与显示。

## 全局二维微调

主界面右下角的无文字绿色按钮用于打开全局校准窗口。窗口包含10个原始角度区间和7个原始距离区间，共70个独立校准单元。每个单元可以分别保存距离修正和角度修正，调整后立即写入用户配置，下次启动自动加载。

除最后一个区间外，各区间均采用左闭右开边界；最外侧角度区间为 `-50°～-40°` 和 `40°～50°`，其中 `40°～50°` 包含最右端；`3.00 m～3.50 m` 包含最右端。落在配置范围外的数据不进行全局微调。

## 精确公式

设基站原始中心距为 `d`（m），基站原始方位角为 `x`（°），最终距离和角度为：

```text
distance = max(0, d)

x < -15          : angle = x - 5
-15 <= x < -10   : angle = 2x + 10
-10 <= x <= 10   : angle = x
10 < x <= 15     : angle = 2x - 10
x > 15           : angle = x + 5
```

五段在 `-15°、-10°、10°、15°` 处连续。取消勾选“场地畸变校准”时，距离仍采用基站中心距，角度直接显示基站原始方位角，便于对照。

旧配置第一次升级到v3时，程序会把人工距离/角度微调归零并自动启用场地畸变校准，避免叠加旧修正。
