# 定位校准说明

## 当前部署方案

当前使用现场测试确定的场地分段校准 v2，旧的45点二维查表和三次角度回归不再参与最终结果。

处理顺序：

1. 可选的5点中值预滤波；
2. 距离减去 `0.25 m`，角度执行场地分段映射；
3. 界面上的距离、角度人工微调；
4. 输出平滑（默认30点中值），界面按实时帧率显示估算总延时；
5. 身份验证、距离分区、声光控制与显示。

## 精确公式

设基站原始中心距为 `d`（m），基站原始方位角为 `x`（°），最终距离和角度为：

```text
distance = max(0, d - 0.25)

x < -15          : angle = x - 5
-15 <= x < -10   : angle = 2x + 10
-10 <= x <= 10   : angle = x
10 < x <= 15     : angle = 2x - 10
x > 15           : angle = x + 5
```

五段在 `-15°、-10°、10°、15°` 处连续。取消勾选“场地分段校准”时，距离仍减 `0.25 m`，角度直接显示基站原始方位角，便于对照。

旧配置第一次由v1升级到v2时，程序会把人工距离/角度微调归零并自动启用场地分段校准，避免叠加旧修正。
