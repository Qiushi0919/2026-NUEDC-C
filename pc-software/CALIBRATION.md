# 定位校准说明

## 当前部署方案

当前使用现场测试确定的场地畸变校准 v3，旧的45点二维查表和三次角度回归不再参与最终结果。

处理顺序：

1. 只对通过协议校验和身份稳定检查的定位帧计数，每6个有效帧分别计算原始中心距和原始方位角的算术平均值；
2. 把6帧平均结果作为一次新的基站原始数据，按其角度和中心距查找全局校准二维区间，并分别加上该格的距离、角度修正值；
3. 对全局校准后的结果执行可选的5点中值预滤波；
4. 距离直接采用中心距，角度执行场地分段映射；
5. 界面上的距离、角度人工微调；
6. 输出平滑（默认30点中值），界面按处理后的实时帧率显示估算总延时；
7. 最终角度限制在 `-45°～+45°`；
8. 身份验证、距离分区、声光控制与显示。

## 全局二维微调

主界面右下角的无文字绿色按钮用于打开全局校准窗口。窗口包含10个原始角度区间和7个原始距离区间，共70个独立校准单元。每个单元可以分别保存距离修正和角度修正，调整后立即写入用户配置，下次启动自动加载。“一键清零”会立即把70格的距离、角度修正全部覆盖为0并保存。

除最后一个区间外，各区间均采用左闭右开边界；最外侧角度区间为 `-50°～-40°` 和 `40°～50°`，其中 `40°～50°` 包含最右端；`3.00 m～3.50 m` 包含最右端。落在配置范围外的数据不进行全局微调。

## 精确公式

设基站原始中心距为 `d`（m），基站原始方位角为 `x`（°），最终距离和角度为：

```text
distance = max(0, d)

x < -15          : angle = x - 5
-15 <= x < -10   : angle = 2x + 10
-10 <= x <= 10   : angle = x
10 < x <= 15     : angle = 2x - 10
x > 15           : angle = x + 5

final_angle = clamp(angle, -45, 45)
```

五段在 `-15°、-10°、10°、15°` 处连续。取消勾选“场地畸变校准”时，距离仍采用基站中心距，角度直接显示基站原始方位角，便于对照。

旧配置第一次升级到v3时，程序会把人工距离/角度微调归零并自动启用场地畸变校准，避免叠加旧修正。
