# 蓝牙声光模块链路

程序同时使用两个独立的 115200、8N1、无流控串口：

- 基站串口：接收 `0x2001` 定位帧，获得信标 ID、距离和方位角。
- 蓝牙串口：连接 MSPM0G3507 声光控制模块，双向收发 `AA 55` 数字钥匙协议帧。

声光模块每 100 ms 发送一次 `ID_REPORT (TYPE=0x10)`，载荷为四位 DIP
拨码 ID。蓝牙在线且 DIP 数据未超时时，软件以 DIP ID 作为唯一的身份验证
目标；手动设置的软件 ID 仅作为蓝牙未连接时的备用值。

软件每 100 ms 返回 `LOCK_STATUS (TYPE=0x20)`，包含检测到的钥匙 ID、验证
结果、区域、变化事件、距离、角度、状态位和质量。模块连续 500 ms 收不到
CRC 正确的状态帧时，应自动关闭蜂鸣器并回到安全闭锁显示。

通用帧为：

```text
AA 55 VERSION TYPE SEQ LEN PAYLOAD CRC_L CRC_H
```

CRC 使用 CRC-16/CCITT-FALSE，从 `VERSION` 计算至最后一个载荷字节。

实际接线/配对后，在顶部“基站”选择定位基站 COM 口，在“蓝牙”选择 Windows
蓝牙串口。两个功能不能选择同一个 COM 口。Windows 能识别出标准蓝牙串口时，
程序会随“启动自动连接”一起自动连接；否则可手动选择并点击“连接蓝牙”。
