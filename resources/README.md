# 项目资料归档

本目录集中保存 2026 电赛原题和数字钥匙项目使用的定位套件开发资料。

## 目录

- `2026年电赛原题合集/`：A、B、C、D、E、F、G、H 题 PDF，以及 D 题附图压缩包。
- `ALX-AOA-FIT定位套件开发资料/`：基站与信标规格书、通信协议、上位机、示例代码、硬件设计文件、结构模型和安装视频。

## 使用提醒

- C 题原题文件：`2026年电赛原题合集/C题_基于无线通信的数字钥匙实验系统.pdf`。
- 厂商上位机、串口驱动和压缩包属于第三方资料，运行前请自行确认来源并进行安全检查。
- 当前项目自己的 Windows 上位机源码位于仓库根目录的 `pc-software/`，不要与资料包中的厂商软件混淆。
